ADDONS

Only what you choose.

Scroll Studio is complete without addons; until you enable one, nothing about addons appears outside Settings → Addons. Each addon is a separate program you install from Settings → Addons → Install from file. It lists what it may do, and every change it suggests is shown first, then applied as one step you can undo.

Before you install

Addons run as programs on your computer with your rights, so install only ones you trust. Settings and keys stay in the addon's own folder, never in your .scro files, and stories made with addons open the same without them.
